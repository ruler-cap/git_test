# 传统点云几何基元分解方案与可行性

## 1. 目标与问题边界

目标是让机器人从 LiDAR 或 RGB-D 点云中得到简化环境表示：一张桌子、一个货架等物体被表示成少量简单几何单元。第一阶段不使用需要训练的神经网络，也不要求输出“桌子”“货架”等语义类别，而是关注：

- 将单个物体或局部场景分解成多个几何单元；
- 每个单元优先使用 OBB（Oriented Bounding Box）；
- 每个 OBB 本身是凸的，但多个 OBB 的并集可以表示非凸结构；
- 保留桌底、桌腿之间、货架层板之间的空隙；
- 优先考虑 CPU 实时性、可解释性和对观测点的保守覆盖。

这里的“保守覆盖”只针对传感器已经观测到的点。传统几何算法不能凭空确定被遮挡的桌腿、背面或内部结构；除非使用已知模板，否则未观测区域应标为未知。

## 2. 方案总览

| 方案 | 核心思路 | 实时性 | 桌子/货架适用性 | 主要限制 |
|---|---|---:|---:|---|
| 递归 OBB 分裂 | 从一个 OBB 开始，按空隙和拟合残差递归切分 | 高 | 较好 | 参数敏感，切分不一定对应真实部件 |
| 平面/薄板结构提取 | 检测平面，将平行或相邻平面组合成层板和支撑 | 高 | 很好 | 单侧观测难以确定厚度，对曲面不通用 |
| 体素/八叉树盒分解 | 体素化点云，将占据区域合并成多个长方体 | 高 | 很好 | 依赖体素分辨率，可能产生碎盒 |
| 图分割/区域生长 + OBB | 按距离、法向、曲率和颜色分割，再拟合 OBB | 中高 | 较好 | 表面片段还需组合成实体部件 |
| 多基元 RANSAC | 反复检测平面、圆柱等解析基元 | 中高 | 较好 | 拟合顺序影响结果，有限范围仍需估计 |
| 传统模板匹配 | 与已知 CAD/点云模板配准，复用预定义部件 | 中 | 固定物体很好 | 模板库外泛化差，遮挡和尺度变化敏感 |
| 网格重建 + 凸分解 | 先重建网格，再做近似凸分解并转换为 OBB | 低 | 完整几何时很好 | 单帧点云不完整，计算链较重 |

## 3. 方案一：递归 OBB 分裂

### 3.1 基本流程

```text
点云
  → 拟合初始 OBB
  → 在 OBB 局部坐标轴上寻找候选切面
  → 对两侧点集分别拟合 OBB
  → 判断切分是否显著改善几何表示
  → 接受切分并递归处理
  → 合并冗余盒并验证覆盖
```

候选切面可以来自：

- OBB 三个局部轴上的投影直方图低密度谷值；
- 点分布的大间隙；
- 满足最小点数约束的分位点；
- 平面边界、法向不连续或曲率突变位置。

切分评分可综合：

- 点到盒表面的距离；
- 盒内空体积代理；
- 切分后的总体盒体积；
- 盒数量惩罚；
- 最小支持点数和最小部件尺度。

### 3.2 优点

- 不要求类别、模板或训练数据；
- 只要输入是点集就能工作，物体类型限制较少；
- 算法结构清楚，盒数量可以通过阈值和最大预算控制；
- 每个叶节点重新投影全部支持点后，可以保证 OBB 包含相应观测点。

### 3.3 局限

- 几何上最优的切分不一定对应桌板、桌腿等真实部件；
- 桌腿与桌板连续连接时，投影直方图不一定存在明显空隙；
- PCA OBB 对离群点、部分视角和近对称物体比较敏感；
- 不同阈值可能导致欠分割或过分割。

### 3.4 可行性判断

可行性高，适合作为通用基线和最终盒集合的分裂/合并优化器，但不一定是桌子、货架的最佳独立方案。

## 4. 方案二：平面与薄板结构提取

### 4.1 基本流程

```text
点云
  → 法向估计
  → RANSAC 或区域生长提取主要平面
  → 合并共面且相邻的平面片段
  → 组合平行面或估计板厚
  → 形成桌板、层板和侧板 OBB
  → 对剩余点聚类，形成桌腿或立柱 OBB
```

可利用重力方向将结构分成：

- 水平薄板：桌面、货架层板；
- 竖直薄板：货架侧板、背板；
- 细长竖直结构：桌腿、立柱；
- 其余残差：交给体素分解或递归 OBB。

CGAL 的 Efficient RANSAC 支持平面、球、圆柱、圆锥和圆环，也允许扩展自定义基元；PCL/CGAL 的区域生长可按法向和平滑度提取连续表面。

### 4.2 优点

- 与桌子和货架的结构特征高度一致；
- 计算量较小，容易利用重力约束稳定姿态；
- 输出部件容易解释；
- 能自然保留层板之间及桌底的空隙。

### 4.3 局限

- 单侧 RGB-D 或 LiDAR 观测到一个平面时，无法直接确定真实板厚；
- 平面支持不足、深度噪声或边缘缺失会导致平面碎裂；
- 桌腿和桌面接触位置可能粘连；
- 圆腿、弯曲支撑和非规则物体需要其他基元或回退方法。

### 4.4 可行性判断

对桌子、货架可行性很高，适合作为结构化物体的主方案。工程上应保留体素或递归 OBB 回退路径，以处理无法被稳定平面解释的点。

## 5. 方案三：体素或八叉树盒分解

### 5.1 基本流程

```text
点云
  → 估计重力和物体主方向
  → 在局部坐标系中体素化
  → 建立占据、自由和未知状态
  → 合并相邻占据体素为长方体
  → 对未覆盖体素继续分解
  → 合并相邻盒并控制盒数量
```

可以采用两类算法：

1. **贪心最大长方体覆盖**：每次寻找能够覆盖最多占据体素、同时不过多吞并自由空间的长方体。
2. **八叉树递归分裂**：全空或足够满的节点停止，不规则节点继续细分，最后把相邻叶节点合并成盒。

体素必须区分：

- `occupied`：观测到的表面或确定占据区域；
- `free`：传感器射线已经穿过的自由空间；
- `unknown`：被遮挡或没有观测到的区域。

不能把 `unknown` 自动当作实体填充，否则会堵塞桌底和货架间隙。

### 5.2 优点

- 天然表达非凸整体、孔洞和空隙；
- 不依赖点顺序和高质量法向；
- 对稀疏 LiDAR 和不规则点密度相对稳健；
- 精度、速度和盒数量可由体素大小直接控制；
- 输出可以直接用于碰撞检测。

### 5.3 局限

- 体素过大会吞掉细桌腿和窄间隙；
- 体素过小会增加内存、延迟和碎盒数量；
- 世界坐标轴对齐会使旋转物体产生阶梯状结果；
- 表面点云并不直接给出实体内部，需要谨慎定义占据规则。

### 5.4 可行性判断

可行性高，可能是最稳定且最容易达到 CPU 10 Hz 的方案。建议先估计重力和主方向，在物体局部坐标系中体素化，再将结果变换回世界坐标系。

## 6. 方案四：图分割或区域生长后拟合 OBB

### 6.1 基本思路

将点、体素或超体素作为图节点，邻接边权综合：

- 欧氏距离；
- 法向夹角；
- 曲率差；
- RGB 颜色差；
- 局部连接是凹边还是凸边。

随后使用区域生长、图切分或谱聚类得到几何片段，再对每个片段拟合 OBB。

### 6.2 优点

- 比 DBSCAN 多利用了法向、曲率和颜色信息；
- 有机会分开空间上接触但方向不同的桌板与桌腿；
- RGB-D 的颜色边界可以辅助处理几何边界不明显的情况。

### 6.3 局限

- 一个长方体可能先被分成六个表面片段，必须再次组合成实体部件；
- 同一平滑表面容易被合并，噪声法向又可能造成过分割；
- 图参数通常随点云密度和传感器噪声变化。

### 6.4 可行性判断

可行性中高，更适合作为平面结构提取或递归 OBB 的候选分割前端，而不是独立完成最终实体分解。

## 7. 方案五：多基元 RANSAC

### 7.1 基本流程

1. 从点云中寻找支持点最多的平面、圆柱或其他基元；
2. 提取并精修该基元的内点；
3. 从剩余点继续检测；
4. 合并参数相近且空间连续的检测结果；
5. 根据内点范围裁剪无限解析曲面；
6. 将有限平面转成薄 OBB，圆柱可以保留或近似成 OBB。

### 7.2 优点

- 不需要训练，参数有明确几何意义；
- 可以混合表达平面桌板、方腿和圆腿；
- RANSAC 对一定比例的离群点具有鲁棒性。

### 7.3 局限

- 标准 RANSAC 拟合的是无限平面或解析曲面，仍需估计有限范围和厚度；
- 顺序式“检测—移除”会使早期错误影响后续结果；
- 同一部件的多个表面可能被识别成多个互不关联的基元；
- OBB 不是由极少点唯一确定的简单 RANSAC 模型，直接随机拟合成本较高。

### 7.4 可行性判断

如果未来允许 OBB、圆柱等混合基元，这条路线价值较高；若第一版只输出 OBB，则它与平面薄板方案相比优势有限。

## 8. 方案六：传统模板匹配

### 8.1 基本流程

对每种已知物体离线保存：

- CAD 或完整点云模板；
- 多视角局部描述子；
- 预先定义好的部件及 OBB；
- 允许的尺度和形变范围。

在线阶段使用 FPFH、SHOT、PPF、LINEMOD 等传统特征和模板方法产生对应关系，再通过 Hough/几何一致性分组、RANSAC 和 ICP 求 6DoF 位姿。匹配成功后，将模板的 OBB 集合变换到场景中。

PCL 提供了局部描述子匹配、Hough 3D/几何一致性分组和多种点云配准接口。

### 8.2 优点

- 对固定工业环境中的已知物体可以获得稳定部件数和拓扑；
- 能利用模板推断被遮挡的桌腿、背面和层板；
- 不需要神经网络训练数据；
- 同时得到物体识别、位姿和几何分解。

### 8.3 局限

- 模板库外的物体无法可靠识别；
- 大幅尺度变化、结构变化和严重遮挡会降低匹配率；
- 大型重复结构可能产生大量错误对应；
- 模板补出的部分并非真实观测，安全系统必须区分 `observed` 和 `inferred`。

### 8.4 可行性判断

对少量已知桌子和货架可行性高，对开放环境可行性低。适合作为可选增强或受控场景方案，不建议作为通用几何分解的唯一依赖。

## 9. 方案七：网格重建后近似凸分解

### 9.1 基本流程

```text
多帧点云
  → 配准和 TSDF/泊松重建
  → 清理网格孔洞及小组件
  → CoACD 等近似凸分解
  → 每个凸部件拟合 OBB
  → 合并并验证碰撞误差
```

V-HACD 和 CoACD 的目标都是将非凸网格近似为多个凸部件。V-HACD 已停止维护，其仓库建议新项目考虑 CoACD。

### 9.2 优点

- 有完整网格时，能较好保留物体凹结构；
- 凸分解结果适合物理引擎和碰撞检测；
- 不局限于盒状或平面物体。

### 9.3 局限

- 算法输入是网格，不是原始点云；
- 单帧或局部点云重建出的网格可能包含孔洞和伪表面；
- 重建和凸分解链路较重，不适合每帧重新运行；
- 将凸部件再次近似为 OBB 会引入第二层几何误差。

### 9.4 可行性判断

适合静态环境建图后的离线或低频更新，不适合第一版逐对象实时点云处理。

## 10. 推荐重点比较的三条路线

第一阶段建议实现并比较：

1. **平面/薄板结构分解**：验证桌面、层板、侧板和支撑是否能被直接恢复；
2. **局部坐标系体素盒分解**：验证非凸空隙、噪声鲁棒性和实时性能；
3. **递归 OBB 分裂**：作为类别无关的通用基线和后处理优化器。

建议同时保留以下简单对照：

- 单 PCA OBB；
- 单近似最小体积 OBB；
- DBSCAN 后每个连通簇拟合一个 OBB。

## 11. 推荐的混合方案

单一传统算法很难同时处理平面结构、细腿、噪声、局部缺失和不规则残差。更有希望的最终路线是：

```text
输入点云
  → 预处理、重力估计和连通聚类
  → 平面/薄板结构提取
      ├─ 稳定水平面 → 桌板或层板候选 OBB
      ├─ 稳定竖直面 → 侧板或背板候选 OBB
      └─ 无法解释的剩余点
              → 局部体素盒分解
  → 对所有候选盒执行递归分裂/合并优化
  → 使用原始保留点重新拟合并扩张 OBB
  → 覆盖验证、空隙验证和盒数量控制
```

这条混合路线的特点是：

- 平面方法提供结构解释和较少的盒；
- 体素方法负责不规则残差和局部缺失；
- 递归 OBB 方法统一控制最终误差、盒数和冗余；
- 全部模块都是传统几何方法，不需要训练模型。

## 12. 数据与验证建议

第一阶段使用 ShapeNet 完整点云验证分解上限，并生成虚拟局部观测模拟未来传感器输入：

- 随机相机位置和单侧可见点；
- 距离相关降采样；
- 高斯深度噪声；
- 随机缺点和块状遮挡；
- 少量离群点；
- 不同可见率和点数量。

优先测试本地数据中的：

- `table`（ShapeNet 类别 04379243）；
- `cabinet`（02933112），用于近似验证层板和柜体结构；
- `chair`（03001627），用于测试细腿和复杂连接。

ShapeNet 是完整、隔离且规范化的 CAD 数据，只能验证几何分解能力，不能替代真实 LiDAR/RGB-D 场景测试。

建议记录以下指标：

- 观测点覆盖率和最大盒外距离；
- 点到盒表面距离 P50/P95/max；
- 相对单 OBB 的总体积下降；
- 已知自由空间被错误覆盖的比例；
- 盒数量及其分布；
- CPU 运行时间 P50/P95；
- 噪声、遮挡和点数变化下的失败率。

## 13. 当前可行性结论

- **只使用 DBSCAN 不够**：它不能可靠拆开相互接触的桌板和桌腿，也不理解层板结构。
- **递归 OBB 是较好的通用基线**：实现直接，但结构解释能力有限。
- **平面/薄板方法最符合桌子和货架**：应作为重点候选，但必须处理单侧观测下的厚度不确定性。
- **体素盒分解最适合稳定实时碰撞表示**：需要在分辨率、碎盒数量和空隙保持之间调节。
- **模板匹配适合已知物体库**：能恢复遮挡结构，但不能作为开放环境的通用方案。
- **网格凸分解不适合逐帧首版**：可以留作多帧静态地图的低频后端。
- 综合来看，最值得验证的是“平面薄板提取 + 剩余点体素分解 + OBB 分裂合并优化”的传统混合管线。
